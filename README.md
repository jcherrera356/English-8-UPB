# English 8 - Global Issues: Israel / Palestine

Presentacion web animada (HTML + [GSAP](https://gsap.com)). No necesita instalar nada.

## Como abrirla

- Doble clic en `index.html`, o publicarla en GitHub Pages (Settings > Pages > Branch: `main` / root).
- Las fotos estan en `img/`, asi que funciona sin internet (menos el video y las fuentes).

## Controles

| Tecla | Accion |
|---|---|
| Flecha derecha / espacio / presentador | Avanzar (algunas slides revelan por pasos) |
| Flecha izquierda | Retroceder |
| `F` | Pantalla completa |
| `Home` / `End` | Primera / ultima slide |

## Archivos

- `guion.txt`: lo que dice cada integrante en cada slide, con las fuentes.
- `index.html`: las slides.
- `js/data.js`: linea de tiempo, quiz, reported speech, referencias.
- Lo que sale en naranja punteado en las referencias esta pendiente.
